## 产品功能

### 笔记（`features/notes/`）

| 能力 | 说明 |
|---|---|
| **列表** `/notes` | 瀑布流卡片；按标题 / 正文搜索；按文件夹与**标签**筛选（叠加关系，都在 URL query 上）；按编辑时间 / 创建时间 / 标题排序；字数统计 |
| **详情** `/notes/:id`、`/notes/new` | 标题 + 正文，**自动保存**（失败弹 Snackbar，草稿不丢）；归属文件夹；顶栏：**版本历史**（新笔记置灰）/「更多」菜单：置顶 / 收藏 / **标签** / 分享 / 删除（二次确认）。正文工具条：撤销 / 重做钉最前，按钮列表末尾是调色（背景），右端：插入图片。正文唯一真相源是 **Quill Delta JSON** |
| **批量操作** | 列表**长按卡片**进入多选（选中集非空即多选态，顶栏换选择形态：退出 / 已选 n 篇 / 全选），底部动作栏：**移动到文件夹 / 收藏(取消收藏) / 置顶(取消置顶) / 删除**。收藏与置顶按选中集**翻转**（全已收藏则显示取消收藏）；删除 = 批量软删进回收站；移动**刷 `updated_at`**（归属变更必须跨设备传播），flags 与单条同一裁决（不刷，见「已知限制」） |
| **标签** | 多对多（`note_tags` + `note_tag_links` 复合主键）。详情「更多」→ 打标弹层：chip 流式选择、输入即建（幂等 createOrGet）、**「完成」才一次性对齐落库**。列表顶栏标签图标 → 筛选弹层（点选筛选 / 再点取消）+「管理标签」入口 → `/notes/tags`（改名 / 删除；删除 = 标签墓碑 + 全部挂接级联摘除）。摘标签也走墓碑（挂接变更要跨设备传播） |
| **版本历史** `/notes/:id/history` | 编辑落库成功后**自动存版**（500ms 防抖天然抑制频率；与最近一版 title+content 全同则跳过），离开页面走 `_leave() → flush()` 同样覆盖。时间线（新→旧）→ 只读预览 →「恢复此版本」（**真回滚**，区别于全局快照的「找回」）：恢复前当前内容先自动存一版防丢。每篇上限默认 50，设置里可调（10–200 离散档位），超限淘汰最旧（物理删，不跨设备传播，两台设备各自收敛） |
| **置顶 / 收藏** | 详情顶栏「更多」菜单里的两个开关，卡片标题行右侧出角标；列表里置顶**恒排最前**（优先于任何排序方式）。两者正交：置顶管「先看哪条」，收藏管「重要的找得到」 |
| **富文本工具条** | `QuillSimpleToolbar`，常驻编辑窗口**下方**一行、可横滚：撤销 / 重做 / 粗体 / 斜体 / 下划线 / 删除线 / 清除格式 / 字号 / 文字色 / 背景色 / 标题样式 / 行高 / 有序 / 无序 / 缩进 / 行内代码 / 引用 / 链接（+ 右端「插入图片」）。撤销 / 重做用 Quill 自带的 undo 栈 |
| **字号** | 工具条「字号」按钮把 `size` 属性写进选中范围（存进 Delta） |
| **纸张背景** | 详情正文工具条按钮列表末尾的 `palette` 循环切换三张图（`paper` / `mint` / `blush`），半透明压在正文下层；列表卡片用同一张 |
| **文件夹** `/notes/folders` | 新建（名称校验在弹窗内联）、拖拽排序、长按菜单（重命名 / 删除）。只列真实文件夹 |
| **最近删除** `/notes/trash` | 笔记 / 文件夹 / 待办三类，各自成段。每行恢复 / 永久删除，顶栏「清空」 |

**图片**：工具条右端按钮 → 系统相册多选 → 在光标处依次插入。图片**不落文件系统**，而是 base64 data-URI 内嵌进 Quill 的 image embed，随正文一起落库 —— 因此不存在「笔记还在、图片没了」的悬挂引用。设置里「图片压缩」默认开，压成 JPEG（短边 1600px / quality 85）。

**桌面拖入图片**：把图片文件从系统文件管理器拖进编辑窗口，松手即插到正文光标处 —— 与上面的按钮**同一条链路**（同一个 use case、同一个压缩开关、同一个插入函数），差别只是图片来源是拖进来的文件路径。拖动经过编辑区时浮出一圈强调色描边（`_DropHighlight`），离开即消失。只认扩展名（`png/jpg/jpeg/gif/webp/bmp`），非图片静默忽略。

**两个贯穿全局的设计**：

- **视图状态不算编辑**。换背景、点收藏、改优先级都走窄通道**只写自己那一列、不刷 `updatedAt`** —— 否则「点一下收藏」会让笔记的「编辑于」跳到今天，也会在同步时被当成一次内容编辑而产生无意义写库。
- **永久删除 = 写墓碑，不是物理删**。详见「数据与同步」。

### 待办（`features/todos/`）

新建、编辑、勾选完成、删除（二次确认，软删除进回收站）。未完成置顶，已完成沉入可折叠的「已完成 N」，顶栏可一键清除全部已完成（也是软删除，所以跨设备能传播）。

- **详情小窗**：点卡片弹出，只读标题 + 提醒时间 + 完成；铅笔回落到编辑弹窗。
- **编辑弹窗**：标题 + 优先级 + 重复规则 + **关联笔记** + 子任务清单。优先级与重复规则**在弹窗里直接改**，与标题同级；子任务在弹窗里即时增删勾（drift watch 推回）。
- **挂接笔记**（`todos.linked_note_id`，一对一）：编辑弹窗「关联笔记」行 → 可搜索的笔记选择弹层（只列未删除笔记），卡片上出「笔记标题」chip、点按跳详情。笔记被物理清扫（30 天墓碑到期）时外键 `SET NULL` 自动摘掉挂接 —— 该变更**不跨设备传播**，对端可能仍挂着旧 id，点 chip 弹「该笔记已不存在」兜底。`UpdateTodoParams.linkedNoteId` 是 **required**：`update` 是全字段覆盖，漏传等于解除挂接（同理，`priority` / `recurrence` 也因此全量透传 —— 此前它们在 `UpdateTodoUseCase` 里被丢弃，属于既有疏漏，已随本批修掉）。
- **优先级**三档（普通 / 重要 / 紧急）。排序上是 `is_done ASC, priority DESC, created_at DESC` —— ⚠️ 优先级排在 `is_done` **之内**而不是整体最前：优先级答「先做哪个」，而「已完成沉底」是分区规则，混排会让一条已完成的紧急待办浮到未完成的普通待办上面，把折叠分组拆散。卡片标题左侧一根色条（重要=accent，紧急=danger），⛔ 不给普通画色条。
- **子任务**：一条待办下的勾选清单，按加入顺序排列。⛔ **没有回收站** —— 它是待办的从属数据，「单独找回一个子项」没有用户场景；删一行是真删，**不跨设备传播**（父待办的墓碑仍然传播，所以「删掉整条待办带子项」在两台设备上一致）。
- **提醒**：小窗里点时钟 → 弹日期 + 时间选择器。确定后**先落库 `reminder_at` 再注册系统通知**，清除则反过来。没授予通知权限时不落库 —— 存了也提醒不了。
- **重复提醒**（daily / weekly / monthly）：⛔ 没设提醒就不让选 —— 重复的是提醒时刻，`reminder_at` 为 null 时重复规则没有东西可作用。`monthly` 遇到没有该日号的月份**夹到当月最后一天**（1 月 31 号 → 2 月 28 号），而不是让 Dart 把它静默卷成 3 月 3 号。
- **提醒与库的全量对账**：`ReminderReconciler` 挂在 `MaterialApp` 之外，订阅待办流（150ms debounce），每次 `cancelAll` 再按库里的现状重建。**一处订阅同时覆盖五件事**：① 重启后平台侧通知全丢（冷启动补回，不需要原生 boot receiver）；② 软删除待办没撤通知；③ 从回收站恢复待办；④ 批量清除已完成；⑤ 把过期的重复 `reminder_at` 往前滚并补满预排。收敛到一处后，新增删除入口不会再漏 —— 它只要改库就会被这条流看见。

> 平台通知的真相源是库，`ReminderScheduler.rescheduleAll` 是「把库投影到平台」的唯一入口。

### 设置（`features/settings/`）

主页 **4 组 13 行**，按「这行改的是谁」分组：**外观**（UI 字体 / 主题 / 语言）、**笔记**（默认排序 / 列表布局 / 图片压缩 / 版本历史上限）、**数据**（数据与同步 / 导入文章 / 最近删除）、**关于**（隐私政策 / 用户协议 / 关于）。UI 字体「系统默认 + 6 款开源中文字体」、默认排序 4 档、列表布局宫格 / 列表、版本上限 10–200 离散档（默认 50）、主题（明暗 + 配色，在二级页选）、图片压缩、关于页（版本号 + 检测更新 + 仓库主页 + 开源许可）。偏好持久化在 SharedPreferences。

「字体」改的是 **UI 文字**：13 级字阶（`AppTextStyles.withFontFamily`）+ `ThemeData.textTheme`（更新弹窗 / 语言选择器等读 Material 默认字阶的地方）。⛔ 不进笔记标题与正文 —— 编辑器文字恒为**平台默认字体**（每篇笔记的 `editor_font_id` 与工具条的「字体」按钮已删除）。

字体入口只有一个（设置「外观」组里的字体行），走底部弹层（`AppFontPickerSheet`）与目录（`lib/core/fonts/`），「系统默认」用 `null` 表达、不触发任何下载。⛔ 弹层里不用各字体自身渲染字体名 —— 那会让「打开弹层」等于下载全部字体。

「数据与同步」与「导入文章」两行都是进入 `features/backup/` 的入口。WebDAV 凭据**不**并进 `AppSettings` —— 那是「App 长什么样」的偏好，凭据是另一回事。

### 数据与同步（`features/backup/`）

导出 / 导入 / WebDAV / 局域网同步共用**同一份快照模型** `BackupSnapshot`（`notes` + `note_folders` + `todos` + `todo_subtasks` + `note_tags` + `note_tag_links` + `note_versions` 全量，**含回收站里的软删除行与墓碑行**；`BackupTodo.linkedNoteId` 同行携带）。

| 动作 | 链路 |
|---|---|
| 导出（备份） | 读全量 → JSON → 临时文件 → 系统分享面板 |
| 导出（Markdown） | 读全量（**排除回收站**）→ 转 Markdown → 临时文件 → 分享面板 |
| 导入 | 选 `.json` → 按 id 合并进本地 |
| 同步 | `GET` 远端 → 与本地合并 → `PUT` 回去 → 落本地 |
| 历史版本 | 列 `history/index.json` → 「找回内容」合并回本地 |
| 局域网同步 | 同一 WiFi 下发现对方 → `POST /sync` 一次往返收敛 |

**两种导出不是一回事**：JSON 是**备份**（含 base64 图片、含回收站与墓碑、能原样还原）；Markdown 是**阅读件**（纯文本、排除回收站、图片渲染成 `[图片]` 占位）。⛔ Markdown 故意不带图 —— 一张 200KB 的 base64 会让 .md 涨到几十 MB，且多数渲染器拒收内联 base64。

**导入文章是独立于快照的一条支路**（`/settings/import`）：选 `.md` / `.markdown` / `.html` / `.htm`（一次可多选），**一个文件落成一篇新笔记**，都进「未分类」。两种格式只走一条转换链路 —— Markdown 先由官方 `markdown` 包转成 HTML，再与 HTML 文件一起经 `flutter_quill_delta_from_html` 转成 Quill Delta；解析器 `NoteImport` 与单向导出的 `NoteMarkdown` 互为反向，同层同目录（后者类注释写明「故意不做双向」，故另立文件）。标题四级回退：HTML 的 `<title>` → 正文首个一级标题 → 文件名。

**逐文件独立成败**：失败原因（不是 UTF-8 / 内容为空 / 格式不支持 / 写入失败）按行落在页面下方的结果列表里，一个坏文件不会中断这一批，也不会只丢一句「导入失败」。笔记列表本身是 drift watch 推流，导入后自动刷新，不需要手动通知。

⚠️ **不能内嵌的内容一律降级成带链接的文字**：编辑器只注册了「内嵌 base64」的图片渲染器（`NoteImageEmbedBuilder`），远程 `<img>` 若留成 embed 会显示「图片损坏」且用户看不到原 URL；表格按段落落库（`transformTableAsEmbed: false`），`<video>` 同理。与导出侧「不静默丢弃」是同一条原则。

#### 合并规则

**只有一条**：逐条比 `max(updatedAt, deletedAt, purgedAt)`，新的赢，一样新保留本地。三类实体共用这个键。软删除与永久删除**都是一次变更**，所以删除靠墓碑跨设备传播，不会被一条更晚的编辑复活。

⚠️ 快照必须**连墓碑行一起读**。加了 `purged_at` 过滤，「永久删除」就退化成「物理删除」，A 机删的笔记会在 B 机同步后复活。

⚠️ **写回时不能漏列**。`BackupLocalDataSource._write*` 用 `insertOrReplace`，而 SQLite 的 `INSERT OR REPLACE` 是 DELETE+INSERT，**未列出的列取默认值**。漏写 `reminder_at` / `deleted_at` / `purged_at` 不是「不同步」，是每次同步把提醒时间清零 / 把已删行复活一批。

⚠️ **`BackupLocalDataSource` 里不能出现 `AppClock.appNow()`**。那份时间戳来自对端，重打本地戳会让每条合并进来的记录都变成「刚刚编辑过」，合并静默退化成「本地全胜」。需要本地时钟的墓碑清扫因此独立成 `TombstoneSweeper`。这条边界由 `test/core/utils/app_clock_usage_test.dart` 扫源码钉住 —— 新加写路径时用了 `DateTime.now()` 没有任何编译期信号，只能靠它。

#### 删除的两级

| 级别 | 落库 | 跨设备 | 保留期 |
|---|---|---|---|
| **软删除**（回收站） | `deleted_at` | ✅ | 直到用户清空 |
| **永久删除** | `purged_at`（墓碑） | ✅ | 30 天后物理删除 |

物理删除必须留墓碑：合并是并集，被物理删掉的行在远端「不存在」，对端会判定「本地这条更新的」并把它原样带回来。保留期必须**长于任何设备的可能离线时长**，否则一台离线一个月的设备上线时会把自己早已清扫掉的行重新带回来。冷启动清扫（`TombstoneSweeper`）无条件执行。

⚠️ **墓碑路径不触发外键**。`notes.folder_id` 的 `ON DELETE SET NULL` 只由物理 DELETE 触发，所以 `FolderLocalDataSourceImpl.purge` 必须在同一事务里显式置空，否则笔记会指向一个已被永久删除的文件夹 id。

#### 快照格式

当前 **v6**。高于它的直接拒绝导入（不静默降级解析）；v1~v5 照读 —— 只加字段不改语义。`subtasks` 是 v4 新增（缺失即空列表），`tags` / `tagLinks` / `noteVersions` 三个列表与 `BackupTodo.linkedNoteId` 是 v6 新增（缺失即空列表 / null）。⚠️ `editorFontId` 曾是 v5 的字段，随编辑器字体功能一并删除且**未升版本号**：新版写出的 v6 不含它，旧版 App 读新快照会把它当缺失（本机笔记字体清零）；反向（新版读带该字段的老快照）不受影响。

#### 其他设计点

- **单文件快照，不是增量队列**。`GET` 到 404 当「远端还没文件」，等价于首次推送，因此不需要冲突状态机。
- **传输 gzip**。`PUT` 发 `Content-Encoding: gzip`，`GET` 按**魔数**判断是否压缩 —— 刻意不信响应头：各家 WebDAV 服务器对 `Content-Encoding` 的处理差异很大，而魔数是内容自身的事实。
- **历史版本只在「内容真的变了」时归档**，判据是三张表的 sha256 指纹，不是整份 JSON 的哈希（`merge` 每次都重写 `exportedAt`，按整份比会让每次空同步都归档一次）。
- **历史用索引文件而非 PROPFIND 列目录**。`207 Multi-Status` 在 nginx / Apache / Nextcloud / Synology 上格式各不相同，索引文件完全复用已跑通的 GET/PUT。
- **先传文件、后写索引**。索引是指针、文件是数据，反过来会让索引短暂指向空气。
- WebDAV 客户端是 **dio 手搓**的，不引第三方包；该 Dio 实例独立，**不加 `LogInterceptor`** —— 请求头里有密码。

## 工程能力

### 路由

`core/router/app_router.dart` 是唯一的 `routerProvider`。`StatefulShellRoute.indexedStack` + `NotesShell` 承载 `/notes`、`/todos` 两个 Tab（切 Tab 不丢列表状态），二级页一律挂 `_rootNavigatorKey` 整屏覆盖。

⚠️ **注册顺序是硬约束**：`new` / `folders` / `trash` 必须注册在 `:id` 之前，否则会被当作笔记 id 吃掉。路径常量只在 `AppRoutes`。router 里**不 watch** `persistentLocaleProvider` —— 会重建 GoRouter 并清空导航栈。

### 本地持久化

`drift`（SQLite）通过 `appDatabaseProvider` 注入；偏好用 `shared_preferences`。**改表后必须跑 build_runner**。快照是应用层的 JSON，它的 `version` 与数据库的 `schemaVersion` 是两件事。

### 多语言

中英双语，取文案用 gen-l10n 生成的强类型 getter，不存在 `context.tr()`：

```dart
Text(AppLocalizations.of(context).note_title);
Text(AppLocalizations.of(context).item_count(count)); // 带参数的是方法
```

三档：跟随系统（默认）/ 中文 / English。唯一真源是 `persistentLocaleProvider`（`Locale?`，null = 跟随系统），⛔ `AppSettings` 里**没有**语言字段 —— 两份偏好表达不出「跟随系统」。

### 主题

色板由 **flex_color_scheme** 从配色方案的主色派生，主题按「明暗 × 配色方案」缓存（`AppTheme.light(scheme)` / `dark(scheme)`）。两个维度**正交**且各自持久化：`themeMode` 管亮度，`colorScheme` 管强调色，都在 `/settings/theme` 上选。

design token：颜色 / 字阶走 `ThemeExtension`（`AppColors`、`AppTextStyles`），间距 / 圆角 / 阴影走常量（`AppSpacing` / `AppRadius` / `AppElevation`）。

### 应用更新

最新版本来自 **GitHub Release**，用 `tag_name` 和 `PackageInfo.version` 比大小，下载页交给 `url_launcher`。启动时查一次有新版才弹窗，关于页可手动查。

⚠️ 版本号真源是 `pubspec.yaml`，发版时它必须和 Release tag 对得上，否则会一直提示更新。

### 桌面窗口

Windows / macOS **没有系统标题栏**：`main.dart` 启动时调 `setUpDesktopWindow()`（`core/window/desktop_window.dart`），用 `window_manager` 把窗口切成 `TitleBarStyle.hidden`，macOS 连红绿灯一并隐藏；标题栏改由 `DesktopWindowFrame` 自绘 —— 32dp 一条，挂 `MaterialApp.router` 的 `builder`，拖动 / 双击最大化 / 最小化 / 最大化 / 关闭都在里面，各页面不必逐个避让。

⚠️ 平台判断走 `defaultTargetPlatform`（**不是** `dart:io` 的 `Platform`），测试里用 `TargetPlatformVariant` 覆盖即可，两端共用一份真源。内容区顶部安全区被 `MediaQuery.removePadding(removeTop: true)` 抹掉 —— macOS 会把透明标题栏的高度报成顶部安全区，不抹会多出一条空隙。

**键盘快捷键**（`core/window/desktop_shortcuts.dart`，挂 `builder` 里 `DesktopWindowFrame` 之内、Navigator 之上 —— 只有这一层覆盖所有页面与弹层）：

| 键 | 行为 |
|---|---|
| `Ctrl+N` | 新建笔记；带上当前分类（`?folder=`），已在笔记二级页时 no-op |
| `Ctrl+F` | 弹出全局搜索面板（`features/notes/presentation/widgets/note_search_panel.dart`），任意页面可用 |
| `Ctrl+S` | 立即把当前编辑页的草稿落库（非编辑页 no-op；`flush()` 非 dirty 直接返回） |
| `Ctrl+,` | 打开设置；已在设置时不重复压栈 |
| `Esc` | 返回上一页（`maybePop` —— 编辑页因此仍走「先落库再退」的 `PopScope` 保护） |

macOS 同组再注册一份 `Cmd`（`SingleActivator` 的 `control` / `meta` 互斥，表达不了「二者其一」，故注册两份）。判断「现在在哪一页」用 `routerProvider.state.uri`：`routerDelegate.currentConfiguration.uri` 对 `push` 出来的页面**是过期值**。⚠️ 这一层在 Navigator **之上**，`Navigator.of(context)` 找不到 Navigator —— 弹层要用 `rootNavigatorKey.currentState?.overlay?.context` 当锚点。

**全局搜索面板**：自持输入框与关键字（⛔ 不写 `noteSearchProvider`，否则在面板里打字会连带过滤背后的列表），复用 `noteListProvider` + `noteListPrefsProvider`；点结果 push 详情，`Enter` 打开第一条，`Esc` 关闭（走全局那层 `maybePop`）。未输入关键字时不订阅查询，面板只留一行输入框。

## 已知限制

用户选择 / 架构现实带来的天花板。**不是 bug**，所以没有修的排期；真到了要修的那天，从这里删掉对应条目。

### 备份与同步

- **合并键依赖设备时钟。** 偏差会**静默**覆盖数据：快的那台赢。落库时间戳统一走 `AppClock.appNow()`，偏移量来自局域网握手的三次采样与 WebDAV 响应的 `Date` 头。⚠️ 但**只在同步那一刻刷新一次**，之后不再校正；彻底解决要改逻辑时钟 / 修订号，代价是改表 + 三条 DAO 全过一遍。
- **恢复文件夹不会把当初落入「未分类」的笔记移回去。** 软删除时 `folder_id` 被置 NULL 且不留痕迹，恢复时无从知道该移哪些。笔记本身没丢，就在未分类里。
- **文件夹重名跨设备会改名而不是丢弃。** `name` 是 UNIQUE，两台设备各建一个「工作」必然撞约束，后者被改成「工作 (2)」。「永不丢数据」优先于「名字必须原样」。
- **同一秒内的删除与编辑会打平，按「保留本地」处理。** drift 把 `DateTime` 按**秒**存，两个键相等时编辑赢、删除没赢。
- **全量同步，没有增量。** 传输已 gzip，但仍是整库 GET + PUT。真嫌慢再上变更日志表。
- **历史版本的「找回」不是「回滚」。** 走的是与导入完全相同的合并路径，而删除的墓碑比任何历史版本都新，所以**当时被删掉的内容不会回来**。UI 确认框里明说了这件事 —— 不是免责声明，是语义边界。
- **历史索引可能与文件不一致。** 上传成功但索引写失败会留一个用户看不见的孤儿文件。不做对账修复：后果是历史少一条，不会损坏数据。
- **墓碑保留期 30 天硬编码**，不可配置。多一个设置项就要多一套偏好持久化与迁移，而 30 天对绝大多数用户已经足够长。

### 笔记（批量 / 标签 / 版本历史）

- **批量置顶 / 批量收藏不跨设备传播**（与单条同一条裁决）：flags 是「视图状态」，不刷 `updated_at`，合并键不认它。真要传播得给 flags 单独一个变更计数列，代价大于收益。
- **标签墓碑永存，不接入保留期清扫。** 标签行体积极小，给几十字节的行做清扫是纯仪式；若将来标签量成为问题再接 `TombstoneSweeper`。
- **跨设备各自新建同名标签会出现两行同名。** `note_tags.name` 故意**不加 UNIQUE**（文件夹那套「改名 (2)」重试对标签是垃圾 UX），靠 `createOrGet` 幂等兜底；撞上了删掉一行即可。
- **批量移动 / 摘挂标签若在同步窗口内与他端编辑撞车，按合并键打平保本地** —— 与「同一秒内删除与编辑打平」是同一条边界。
- **版本淘汰不跨设备传播。** 超上限物理 DELETE 最旧版本，对端快照里还留着 → 合并回来；两台设备各自存满后按 `createdAt` 各自淘汰，最终收敛到同一批最近版本。给几十 KB 的正文行做永存墓碑，快照只会越滚越大，收益为负。
- **版本历史上限是离散档位（10–200）**，不做自由输入。步进器表达不出「档位感」，自由输入则要处理越界回写与即时校验。
- **恢复版本后详情页整页重挂**（`go` 回详情而非 `pop`）：编辑器只灌一次值，`pop` 回去会看到恢复前的草稿还停在屏幕上。代价是返回栈被重置 —— 从更深页返回的路径变直了。
- **笔记被物理清扫时 `todos.linked_note_id` 的 `SET NULL` 不跨设备传播。** 对端可能仍挂着已被清扫的笔记 id，点 chip 弹「该笔记已不存在」兜底；静默清掉挂接反而让用户以为没挂过。

### 导入文章

- **只认 UTF-8。** 中文 `.md` 里 GBK / GB18030 很常见，那类文件会**逐个**报「读不出文本」而不是静默乱码（带 BOM 的 UTF-8 会先削 BOM 再读，不受影响）。做编码探测要引包，且猜错比报错更难排查，故不做。
- **远程图片不下载。** 正文里只留一行带原 URL 的文字占位 —— 抓图要联网、会让导入从毫秒级变成「看网速」，且抓一半失败更难解释。要带图的完整内容就走 JSON 快照。
- **没有体积上限，解析在主 isolate 上同步跑。** 几百 KB 的文件无感；几 MB 的 HTML 会有可感卡顿。与快照导入「不设上限」同一条裁决。
- **代码块的排版保不住原样。** 转换器在解析前会抹掉输入的所有换行与每行首尾空白：缩进丢失；多行代码块靠把换行换成 `<br>` 才不至于**粘成一行**（那是内容损坏），但其中只有最后一行带代码块样式。要逐行都对得上只能换掉这个转换器。
- **一个文件一篇笔记，不按标题拆分。** `#` 一级标题只用来取标题，不当分篇边界。

### 桌面窗口

- **启动瞬间会闪一下系统标题栏。** 窗口由 runner 在 Dart 起来之前就显示了（Windows 的 `runner/main.cpp` 建完就 `Show()`，macOS 的 nib 同理），无边框样式只能等 Dart 跑起来再切。要彻底消掉得改原生建窗时的样式。
- **自绘标题栏的三个窗口按钮没有 tooltip / 无障碍标签。** 用的是 `window_manager` 自带的 `WindowCaption`，只有图形没有语义；要补就得自绘这三个按钮外加 4 条 l10n 文案。
- **快捷键不可配置，且只覆盖 Ctrl / Cmd 这一组。** 没有「改键」界面，也不做菜单栏；移动端按不出这些组合键，那一层只是原样透传（不按平台开关，是为少一个平台分支）。
- **`Ctrl+S` 只落库、不给任何反馈。** 自动保存本来就是 500ms 内的事，成功时静默；失败仍由编辑页既有的 Snackbar 提示。
- **全局搜索面板不做 debounce、不分组、不限条数。** 与列表页内联搜索同一条裁决（参数化 `LIKE` 全表扫描在本项目笔记量级下几十微秒），结果靠面板内滚动。
- **拖入只认扩展名**（`png/jpg/jpeg/gif/webp/bmp`）。桌面拖入的 `XFile` 没有 `mimeType`，所以一个改过名的文件（内容不是图片却叫 `.png`）会插成「图片损坏」占位而不是被拦下。
- **拖入的光标位置取编辑器当前 selection。** 编辑页刚打开、正文从未获得过焦点时它是 `-1`，`clamp` 后落在文档开头 —— 与工具条「插入图片」按钮的既有行为一致（点一下正文即可定光标）。

### 凭据与传输

- **局域网同步没有任何认证。** 同网段任何设备都能读写你的全部笔记。知情选择（局域网内可信），UI 上有常驻明文提示。
- **WebDAV 密码明文落 SharedPreferences**，且走明文 HTTP 时同网段可嗅探（Basic Auth 只是 base64）。App 无账号体系、无后端，设备本地存储已被系统沙箱保护；为它引 keychain 是给一个本地 App 上锁自己的门。
- **UDP 广播发现会被网络屏蔽**（AP 隔离、公司 / 访客 WiFi）。页面提供「手动输入地址」兜底，开启「允许被连接」后会**把本机 `IP:端口` 显示出来**让用户照着抄。
- **公网 http 的 WebDAV 在 iOS 上会被拦、Android 上能通**（iOS 只放行私网与 `.local`）。有意的不一致：iOS 侧更安全也更好过审核。

### 通知

- **重复提醒只支持 daily / weekly / monthly**，⛔ 不引 RRULE。而且一次**只预排 5 场**（`kOccurrenceHorizon`）—— 本地通知没有可靠的「响了就回调」，「响完再排下一场」做不到，所以用预排换续航；每次冷启动的对账会把过期的往前滚并补满。真要无限重复得接 `workmanager`。
- **删掉一条子任务不跨设备传播。** 子项没有删除墓碑，对端同步后会把这条子项带回来。父待办的删除仍然传播，所以「删掉整条待办」是一致的 —— 只有「单独删一个子项」会复活。
- **对账有 150ms debounce。** 「刚设的提醒在 150ms 内退出 App」可能来不及注册 —— 下次冷启动会补上。
- **⛔ Windows 没有权限接口**：toast 开关在系统设置里，没开时到点静默不弹。

### 字体

- **字体文件不打包，首次选中要联网。** 目录（`lib/core/fonts/app_font.dart`）里 6 款开源中文字体由 `chinese_font_library` 的 `DynamicFont.url(...)` 按需下载，缓存到 `getApplicationSupportDirectory()`；**同一字体只下载一次**，之后离线可用。首次下载体积：站酷快乐体 1.5MB / 得意黑 2.1MB / 等宽 JetBrains Mono 183KB / 思源黑体 17.7MB / 思源宋体 25.1MB / 霞鹜文楷 25.6MB —— 弹层每行标了体积给用户一个耗时预期。
- **下载失败 = 留在弹层里、不改当前选择。** 不落库、不换字体，弹一句「字体下载失败」后可再点一次重试（失败不进缓存）。
- **冷启动时字体是「先默认、后换过来」。** 字体注册进引擎是异步的，`fontFamilyOf` 的加载期间 `AsyncValue.value` 为 null → 先用系统字体渲染，注册完成自动换。⛔ 不阻塞启动；缓存文件被清且离线时回落系统默认（只记日志，不弹提示）。
- **字体目录是本机偏好，不是文档数据。** 用它渲染的前提是「本机装过」；⚠️ 换设备 / 清数据后，若某款字体已从目录下线，设置里那个 id 会解析成系统默认（`fontFamilyOf` 与 `SettingsRepositoryImpl` 都只认目录里存在的 id）。
- ⛔ **笔记正文里遗留的 `font` 属性不做迁移**：它是历史版本按选中范围写进 Delta 的内联属性，优先级高于编辑器基准样式（平台默认字体），未注册的族名按 Flutter 既有行为回落。每篇笔记自己的 `editor_font_id` 列随功能删除，老库残留的列**不再被读写**（无迁移）。
- ⛔ **不引 `useSystemChineseFont()`**：它改的是「系统中文字体按原生字重渲染」，与「选字体」是两件事，本期不引入这一层行为变更。
- **行内代码不跟随正文字体**：Quill 的 inline code 样式把族名硬编码成 `Menlo` / `Roboto Mono`（`default_styles.dart`），要覆盖得从 `QuillEditorConfig.customStyles` 灌 `DefaultStyles`——代码本来就该等宽，不为此加一条注入链。
